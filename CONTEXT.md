# CONTEXT.md — yh-cybersec-prototype

## Domän
OT-säkerhet (Operational Technology) — proximity-baserad åtkomstkontroll för industriella miljöer.

## Language

### Enheter

**SHALLOT**:
Secure Hardware-Assisted Local LoRa Trust — proximity-based access control for industrial environments.
_Avoid_: shallot, Shallot

**PAW**:
Personal Access Wearable — the badge carried by personnel. Feather RP2350 + E-ink + LoRa.
_Avoid_: badge, credential, wearable (use PAW when referring to the device)

**Mama Bear**:
Air-gapped root of trust. Arduino UNO Q. Provisions keys via USB-serial.
_Avoid_: gateway, server

**FIDO Key**:
Signing module. ESP32-S3-Nano running PicoFIDO. Receives nonce over USB-serial from PAW, returns HMAC-SHA256 signature.
_Aavoid_: authenticator, key (ambiguous)

**Field Node**:
Edge-enforcement point. Pico 2 W + LoRa + relay. Broadcasts beacons, verifies auth, controls relay.
_Avoid_: lock, actuator, node

### Mjukvara

**SHALLOT Harness**:
Fristående personlig agentplattform för projektledning, utveckling, forskning, cybersäkerhetsarbete och fysiska byggen. Börjar med SHALLOT som enda workspace men kan senare bära separata personliga och projektspecifika minnen. Skild från Cub, som är den operativa agenten i OT-demon.
_Avoid_: Cub, SHALLOT-agenten (otydligt vilken agent)

### Kommunikation

**Beacon**:
Plaintext LoRa frame from Field Node to PAW. Contains node_id, timestamp, nonce. Not encrypted, not signed. 13 bytes.
_Avoid_: heartbeat, signal, broadcast

**Auth request**:
Signed LoRa frame from PAW to Field Node. Contains badge_id, nonce (from beacon), HMAC-SHA256 signature from FIDO Key. 41 bytes.
_Avoid_: response, reply, signed beacon

**Nonce**:
Random 32-bit value generated by Field Node per beacon. Challenge that PAW must sign. One-time use per beacon cycle.
_Avoid_: token, counter, sequence number

**Epoch-nyckel**:
Rolling HMAC secret synced via Mama Bear USB-serial. Used for FIDO Key signature rotation. Auth frame includes `day` field so Field Node can enforce offline revocation (day > valid_until → reject).
_Avoid_: session key, symmetric key

### Säkerhet

**RSSI gating**:
Two thresholds for different purposes:
- **On-site threshold** (>-40 dBm): PAW considers itself within 1-2 meters of Field Node
- **Fail-closed threshold** (<-70 dBm): Field Node rejects auth requests with weak signal
_Avoid_: proximity check, signal check

**Fail-closed**:
Default safe state. Relay OFF. Triggered by: heartbeat timeout (>5s), RSSI below threshold, invalid signature, replay attempt, epoch expired (day > valid_until).
_Avoid_: fail-safe, safe mode, watchdog

**Single-occupancy**:
Field Node accepts one PAW at a time. First valid auth wins. Concurrent PAWs timeout and retry. Human reaction time (200-300ms) makes true simultaneous presses impossible.
_Aavoid_: multi-user, concurrent access

**Privacy masking**:
E-ink display blank when PAW is off-site. Credentials visible only when beacon received and RSSI above on-site threshold.
_Avoid_: display off, screen blank

**Baseline**:
Physical key + paper logbook. The analog fallback when electronic system is unavailable.
_Avoid_: manual, offline,传统

### Ramverk

- NIST CSF 2.0, NIST SP 800-53r5, MITRE ATT&CK, CIS Controls v8
- PicoFIDO: FIDO2/CTAP 2.2, WebAuthn, HMAC-Secret

### Hårdvara

- PAW: Adafruit Feather RP2350 + E-ink + Core1262-HF LoRa + 400mAh LiPo
- FIDO Key: ESP32-S3-Nano (PicoFIDO)
- Field Node: Pico 2 W + Core1262-HF LoRa + relay
- Mama Bear: Arduino UNO Q
- Budget: 4000 SEK | Tid: 4 veckor MVP
